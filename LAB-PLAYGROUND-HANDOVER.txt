AdeeboLab playground — 27 November 2026

Owner requirements
No accounts, ever. Users import/export project files. Browser caching is a convenience. Start fresh must open an empty project. QR codes can move a copy to another device. Marketing comes later.

Behavior
- Save project stays visible in the first toolbar row on phone and desktop. Ctrl/Cmd+S exports the editable JSON project, rather than only requesting browser persistence.
- Project menu offers Start fresh, Open, Save, QR sharing and existing PNG/SVG exports.
- Start fresh opens and caches a blank project; it does not erase other cached diagrams. Import assigns a separate local project ID, preserving existing cached work.
- Home describes browser-only caching and file ownership. App-specific measured-network tiles are hidden on the public playground. They remain available when the Windows app supplies AM_VIEWS.
- Selected-item Rename/Delete controls work without a hardware keyboard. Secondary tools scroll on narrow screens; Save/Project stay accessible.
- No registration, cloud service, project upload or live collaboration was added. The existing connect-src 'none' policy remains intact.

QR snapshots
Project data is gzip-compressed where supported, encoded into the URL fragment and drawn using the site's own QR encoder. No third-party QR service is used. The fragment is not part of HTTP requests. A receiving browser validates the snapshot, assigns a new local ID and removes the fragment from the address after opening so refresh does not replay an old snapshot.
Anyone with a code/link can read that snapshot. This is stated in the dialog. It is a copy, not live sync. Codes are limited to links of 1,500 characters for readability; detailed projects can use a copyable link up to the transfer limit or a project file. Older browsers without compression can use plain snapshots; browsers unable to decompress a received link are directed to files.
Transfer links are bounded to 12,000 characters and decoded data to 2 MB. Invalid or oversized shared input preserves cached diagrams. Imports retain the existing document limits.
