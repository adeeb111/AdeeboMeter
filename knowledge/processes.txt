== System
friendly: Windows kernel
cat: Windows core
close: 2
tag: The engine room. Everything else rides on it.
what: Runs the heart of Windows: memory, disks, network and every driver work through here.
how: It isn't an app at all - it's the kernel itself plus the drivers that talk straight to your hardware. Its CPU and memory are really your drivers' work.
why: No kernel, no Windows. Every file you open and every packet you send passes through it.
without: It can't be stopped - if it fails you get a blue screen. If it's busy, a driver is struggling (Wi-Fi, disk, or the antivirus checking files).

== Idle|System Idle Process
friendly: System Idle
cat: Windows core
close: 2
tag: Not a program - it's how much of your CPU is free.
what: Shows the CPU time nobody is using.
how: When there's nothing to do, the processor runs this placeholder and naps to save power and heat.
why: Pure bookkeeping, so the numbers add up to 100%.
without: Nothing to remove. A big 'Idle' number is good news.

== Registry
friendly: Registry
cat: Windows core
close: 2
tag: Windows' settings book, kept in memory.
what: Holds the registry - the giant database of settings for Windows and every app.
how: The kernel keeps the registry in this process's memory so lookups are instant, and saves it to files on disk.
why: Every app setting, driver option and policy your IT team pushes lives there.
without: Windows couldn't remember anything - it wouldn't even boot.

== Memory Compression
friendly: Memory Compression
cat: Windows core
close: 2
tag: Zips your RAM so it lasts longer.
what: Squeezes memory that apps aren't using right now, instead of writing it out to the disk.
how: Pages that go quiet get compressed in RAM. When the app needs them back, they're unzipped in microseconds - far faster than reading the page file.
why: It makes your memory feel bigger when Outlook, Teams and Edge all want room at once.
without: Windows would hit the disk sooner and everything would feel slower. If it's large, your RAM is simply full - close an app or two.

== Secure System
friendly: Secure System
cat: Security
close: 2
tag: A locked vault inside your PC.
what: Runs Windows' virtualization-based security - a separate, protected world for secrets.
how: The CPU's virtualization splits memory in two, so even malware with admin rights can't read what's inside the vault.
why: It guards your sign-in secrets and keeps the kernel honest (Credential Guard, memory integrity).
without: Stealing passwords would be much easier. On a work laptop IT turns this on deliberately.

== LsaIso
friendly: Credential Guard
cat: Security
close: 2

how: lsass asks it to do the secret work; the actual keys never leave the protected world.
why: Even an attacker with admin rights can't copy your credentials out of memory.
without: Credentials would sit in normal memory - the classic target for attackers.

== svchost
friendly: Service Host
cat: Windows core
close: 1
tag: An apartment building for Windows services.
what: Each copy is home to one or more Windows services: DHCP (your IP address), DNS client (name lookups), Wi-Fi, Windows Update, time sync, Bluetooth and dozens more.
