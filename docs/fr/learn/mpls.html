MPLS : des étiquettes à travers le cœur du réseau

Une courte étiquette devant le paquet indique le prochain saut.

À l’entrée du réseau, le paquet reçoit une étiquette. Les routeurs du cœur la remplacent le long d’un chemin LSP préétabli sans lire l’adresse IP intérieure.

Déroulement des échanges

Routeur du clientRouteur de bordure PE1

  1. Routeur du client vers PE1 : paquet IP vers 10.2.0.9

  2. PE1 → P1 : étiquette 300 (chemin), 17 (VPN client), puis paquet

  3. P1 → P2 : étiquettes 410 et 17, paquet (remplacement)

  4. P2 → PE2 : étiquette 17 et paquet (étiquette extérieure retirée)

  5. PE2 → site B du client : paquet IP vers 10.2.0.9

Quand ça tourne mal

Chaque étiquette ajoute 4 octets. Une MTU insuffisante dans le cœur fait perdre les gros paquets.

Pour aller plus loin

LDP distribue les étiquettes, ou le routage par segments les annonce dans l’IGP. Une pile peut porter une étiquette extérieure de chemin et une intérieure de client ou service. Cette dernière permet VPN, services Ethernet et ingénierie de trafic sur le même réseau. L’avant-dernier routeur retire souvent l’étiquette extérieure. Traceroute peut montrer les étiquettes par extensions ICMP ou masquer les sauts si le fournisseur les transporte en tunnel.
