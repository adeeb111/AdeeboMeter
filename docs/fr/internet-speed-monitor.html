AdeeboMeter

Surveillance Internet gratuite pour Windows

Lancer les vérifications

  1. Regardez les débits avant la tâche pour connaître l’activité au repos.
  2. Reproduisez le problème, notez l’heure et comparez débits et délais du routeur et d’Internet.
  3. Mettez les gros transferts en pause si possible, puis répétez et comparez.

Quoi vérifier ensuite

  • 0 Mb/s au reposNormal. Lancez la tâche à mesurer.
  • Délai accru pendant le téléversementMettez le téléversement en pause et répétez.
  • Délai accru malgré peu de traficComparez routeur et Internet.
  • Un téléchargement lentEssayez une autre destination.

Exemple concret

Une sauvegarde en ligne perturbe les appels. Notez l’heure, suspendez-la et recommencez l’appel. Si le délai redevient normal et que le phénomène se répète, le lien est plus clair qu’un simple débit.

Pourquoi ça aide
  • Débit actuel : trafic actuel (Mb/s).
  • Test de débit : capacité vers un serveur de test (Mb/s).
  • Utilisation des données : trafic cumulé (Mo ou Go).

Les files d’attente augmentent le délai. Un appel peut donc ralentir malgré un débit élevé. Consultez débit et délai pour comprendre le mécanisme.

Utiliser AdeeboMeter sur Windows

AdeeboMeter affiche trafic et connexion ensemble. Utilisez Historique pour revoir la période si activé. Si plusieurs services bloquent, utilisez les tests Wi-Fi ou fournisseur pour localiser le problème.
