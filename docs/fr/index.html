AdeeboMeter · Theory of Everything19
Sécurité

Conçu pour la sécurité, validé par des vérifications.

Aucun interpréteur de commandes

Outils Windows lancés par leur chemin System32 complet, avec arguments fixes, délai limite et objet de travail fermé avec l’application.

Entrées validées

Destinations validées avant chaque exécution. Captures limitées au dossier d’AdeeboMeter.

TLS correctement validé

TLS 1.2 / 1.3 seulement. Windows valide les certificats; rien n’est transmis sur une connexion non fiable.

DLL de System32 seulement

Pour tout le processus : une DLL déposée près de l’EXE dans Téléchargements n’est jamais chargée.

Moins de points d’attaque

Aucun programme de mise à jour, sérialiseur binaire, analyseur XML ni secret dans le code. Les secrets RADIUS, communautés SNMP et mots de passe v3 sont masqués et ne sont pas conservés.

Les limites

Les limites de Windows sans droits d’administrateur ni service infonuagique.

Numéros AS et données BGP

Exige un service Internet, accessible seulement par les recherches en ligne activées pour une durée limitée. Sinon, les noms des routeurs donnent des indices.

Traceroute TCP / UDP

Exige des sockets bruts et les droits d’administrateur. Les traces utilisent ICMP.

RTT par connexion

L’activation exige les droits d’administrateur. Le trafic par application vient donc de la capture en direct.

Cache DNS

Réservé aux administrateurs sur certaines versions de Windows; les noms viennent alors de la capture.

Tests de débit

Seulement vers votre propre serveur (iperf3, bufferbloat, TWAMP-light). AdeeboMeter n’ouvre aucun port en écoute.

Dans un tunnel ou chez le fournisseur

Seulement déduit des mesures, impossible à voir directement.

Marquage DSCP

Windows efface généralement le marquage demandé, sauf si une politique QoS l’autorise. Une capture permet de le confirmer.

Écrans de mises à l’échelle différentes

Entre écrans à 100% et 200%, Windows redimensionne la fenêtre; l’image peut être un peu moins nette.

Politiques

Signature du code et confidentialité.

✓

Politique de signature du code

Depuis la version 1.1.5, le code est signé par Open Source Developer MdAhasanul Adeeb Khan avec un certificat libre Certum. L’horodatage permet de valider les signatures après son expiration. Chaque fichier de version est compilé par le processus GitHub Actions du projet à partir du code public, avec chaque action liée à un commit précis. L’auteur signe ensuite le fichier EXE produit. La version fournit son empreinte avant signature, couverte par la preuve de provenance, et après signature. Chaque version est approuvée manuellement. Rôles de commit, de révision et d’approbation : adeeb111, avec authentification multifacteur.

✓

Politique de confidentialité

AdeeboMeter envoie des données à d’autres systèmes réseau seulement à votre demande. Aucun port en écoute, aucune télémétrie, aucun compte ni programme de mise à jour. Les vérifications et outils contactent seulement l’adresse saisie ou affichée; À propos indique chaque paquet envoyé selon vos paramètres.

✓

Recherches en ligne

Désactivées au départ. Activées pour 5 minutes à 3 heures, elles transmettent seulement les adresses IP publiques aux services suivants : RIPEstat et PeeringDB, puis s’arrêtent automatiquement. Le reste demeure sur votre PC et est supprimé à la désinstallation.
