5G NSA vs SA, and why your router says 5G but behaves like 4G

Non-standalone borrows the 4G core; standalone is 5G all the way.

NSA adds 5G radio to a 4G anchor cell: the phone signals over 4G and gets extra speed on 5G, but the core is still the 4G one. SA uses a 5G core and 5G for everything.

How the conversation goes

Phone4G anchor cell

  1. Phone to 4G anchor cell: attach (as in 4G)

  2. 4G anchor → 5G cell: add a 5G leg for this phone (EN-DC)

  3. 5G cell → Phone: extra capacity

  4. Phone → 4G core: all signalling stays here

  5. 4G core → Internet: your data

When it goes wrong

A device that only supports SA in a place that only has NSA (or the reverse) falls back to 4G - working, slower.

Going deeper

NSA (option 3x) gave early 5G its speed without a new core. Features that need the 5G core - network slicing, the lower-latency user plane, RedCap devices, the newer session handling - only come with SA. On NSA, losing the 4G anchor drops the 5G leg too, so a "5G" icon can flicker while data stalls. Routers usually show which one they're on (EN-DC means NSA). Latency on NSA is close to good 4G; on SA with a nearby UPF it can be lower.
