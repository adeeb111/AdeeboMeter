winlogon.exe - your sign-in

Sign-in screen, Ctrl+Alt+Del, lock and sign out.

Handles signing in, locking (Win+L) and Ctrl+Alt+Del.

How the conversation goes

Youwinlogon

  1. You to winlogon: Ctrl+Alt+Del

  2. winlogon → lsass: check PIN

  3. winlogon → explorer: start your desktop

When it goes wrong

If sign-in hangs, a startup program or a profile problem is usually behind it.
