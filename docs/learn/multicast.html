Multicast - one TV stream for thousands of homes

Sent once, copied only where someone is watching.

A live channel is one multicast group address. Your set-top box joins the group; routers copy the stream only onto links where somebody is watching.

How the conversation goes

Set-top boxHome router

  1. Set-top box to Home router: IGMP join 239.1.1.5 (channel 5)

  2. Home router → Provider router: join 239.1.1.5

  3. Provider router → Toward the TV head-end: PIM join (S,G)

  4. TV head-end → Many routers: one stream, copied at each branch

  5. Provider router → Set-top box: channel 5, 8 Mbps

When it goes wrong

IGMP snooping off on a home switch floods the TV stream to every port - Wi-Fi collapses. A join that never reaches the tree gives a black screen while the internet works fine.

Going deeper

The box sends an IGMP "join" (MLD on IPv6) when you change channel; the access switch or router notes it (IGMP snooping keeps it off ports that didn't ask). Routers build a distribution tree toward the source with PIM - usually source-specific (PIM-SSM: "this channel from that server"). One 8 Mbps channel watched by 50,000 homes costs the core 8 Mbps, not 400 Gbps. Channel change speed depends on how fast the join reaches a router that already has the stream - providers add fast-channel-change servers that blast a short unicast burst while the multicast joins. Ordinary internet streaming (Netflix, YouTube) can't use multicast - every viewer pulls their own copy.
