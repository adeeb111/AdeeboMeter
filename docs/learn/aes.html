Encryption and keys

AES - one key locks and unlocks

The fast lock that carries all your data.

AES uses one shared key: the same key locks and unlocks. It is fast enough to encrypt everything you send.

How the conversation goes

Your PCServer

  1. Your PC to Server: AES-locked data (key K)

  2. Server to Server: unlock with the same key K

  3. Server to Your PC: AES-locked answer (key K)

When it goes wrong

The hard part isn't the lock - it's getting the same key to both sides without anyone seeing it. That's what the key agreement solves.

Going deeper

AES-GCM also seals the data, so any change on the way is caught. A 128-bit key already has more combinations than anyone could ever try; 256-bit is for the long haul.
