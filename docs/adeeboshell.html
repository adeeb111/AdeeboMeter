Try your first check

  1. Open the full AdeeboMeter window and choose AdeeboShell. Ctrl + ` opens it from another page in the app.
  2. Type status and press Enter. Read what the app has measured so far; an unavailable reading is not a pass.
  3. Type ls /tools to explore the tool groups. Use help before trying an unfamiliar command.

Tab completes a command. Ctrl+C stops the current command.

Start with the question

  • Is my connection up?Type status. Read the current measurements before choosing the next check.
  • Which check should I run?Type ls /tools. Explore the built-in groups, then read the command’s help.
  • What does ping tell me?Type help ping. A probe reply is one clue; compare it with what your application is doing.

AdeeboShell is built into the Windows app. These are AdeeboShell commands, not instructions for PowerShell or Command Prompt.

Read the result

  • A slow or missing answerCompare it with another destination and a good moment. One failed check does not identify the cause on its own.
  • A command you do not recogniseRead its help first. Commands can send network traffic or work with files.
Can AdeeboShell change my Windows files?

No. Windows folders and drives are read-only in AdeeboShell. File changes stay inside AdeeboMeter’s /data folder.

How do I stop an AdeeboShell command?

Press Ctrl+C to stop the current command.
