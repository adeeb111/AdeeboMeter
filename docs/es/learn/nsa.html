5G NSA y SA: por qué aparece 5G pero se comporta como 4G

NSA usa el núcleo 4G; SA es 5G de principio a fin.

NSA añade radio 5G a una celda base 4G. La señalización sigue por 4G y 5G añade velocidad, con núcleo 4G. SA usa núcleo y radio 5G para todo.

Cómo transcurre la comunicación

TeléfonoCelda base 4G

  1. Teléfono → Celda base 4G: conexión como en 4G

  2. Base 4G → Celda 5G: añadir enlace 5G al teléfono (EN-DC)

  3. Celda 5G → Teléfono: capacidad adicional

  4. Teléfono → Núcleo 4G: toda la señalización se queda aquí

  5. Núcleo 4G → Internet: tus datos

Cuando falla

Un equipo solo SA donde hay solo NSA, o al revés, vuelve a 4G: funciona más lento.

Más a fondo

NSA (opción 3x) dio velocidad al primer 5G sin cambiar el núcleo. Particiones de red, plano de datos de menor latencia, RedCap y nuevas sesiones requieren SA. En NSA, perder la base 4G corta también 5G: el icono puede parpadear mientras se atascan los datos. Los routers suelen indicar el modo; EN-DC significa NSA. La latencia NSA se parece a una buena 4G; SA con UPF cercana puede reducirla.
