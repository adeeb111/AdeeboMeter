Medidor de velocidad de internet gratis para Windows

Ejecuta las pruebas

  1. Mira las velocidades antes de empezar para conocer el estado en reposo.
  2. Repite el fallo, anota la hora y revisa subida y bajada junto a latencia del router e internet.
  3. Si puedes hacerlo sin problemas, pausa otras transferencias grandes y repite. Compara las pruebas.

Qué revisar después

  • 0 Mb/s en reposoNormal. Inicia la tarea que quieres medir.
  • El retraso sube al subir datosPausa la subida y repite.
  • El retraso sube con poco tráficoCompara latencia del router e internet.
  • Solo una descarga va lentaPrueba otro destino.

Ejemplo práctico

Una llamada falla siempre que sube una copia grande. Anota la hora, pausa la copia y repite. Si el retraso vuelve a lo normal y el patrón se repite, tienes una pista mejor que la velocidad sola.

Por qué funciona
  • Velocidad actual: tráfico que se mueve ahora (Mb/s).
  • Velocidad: capacidad hacia un servidor de prueba (Mb/s).
  • Uso de datos: tráfico acumulado (MB o GB).

La latencia puede crecer si el tráfico espera en una cola. Por eso una llamada se retrasa aunque sigan pasando muchos datos. Mira velocidad frente a retraso para entender cómo funciona.

Usa AdeeboMeter en Windows

Abre AdeeboMeter para ver tráfico y conexión juntos. Usa Máquina del tiempo para revisar el periodo si había historial activo. Si varios servicios fallan, usa las pruebas Wi-Fi frente a proveedor para acotar la ruta.
