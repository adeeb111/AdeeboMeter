买价、卖价和点差

同时有两个价格：买家支付的价格和卖家收取的价格。

出价是人们现在愿意支付的最佳价格；卖价是某人出售的最低价格。它们之间的差距就是点差——你每次交易时除了佣金之外还要支付的费用。

通信如何进行

买家交易所

  1. 买家交流： 最佳出价$20.00

  2. 卖家→换货：最好问$20.10

  3. 你 → 交换：在市场上购买

  4. 交易所→你：填写在$20.10

出问题时

小型、很少交易的公司和非正常营业时间的点差很大；在那里进行“廉价”交易的成本可能比费用还要高。
