4G 核心网：MME、SGW、PGW、HSS

MME 处理信令，网关承载数据。

MME 验证身份并跟踪所在区域。SGW 从基站承接数据；PGW 分配 IP 并按 APN 接入互联网。HSS 保存用户资料。

通信如何进行

eNodeBMME

  1. eNodeB 到 MME： 初始 UE 消息（附着请求）

  2. MME→HSS：该IMSI的认证信息

  3. MME→SGW：创建会话

  4. SGW → PGW：创建会话（APN 互联网）

  5. SGW→MME：创建会话响应——PGW分配的IP 100.70.3.9

出问题时

MME 故障可能使手机完全无法附着。PGW 或 APN 故障则表现为已附着但无数据，信号格仍正常。

更深入

信令从 eNodeB 经 S1-MME 到 MME，使用 S1AP 承载 NAS。数据走 GTP-U 隧道：eNodeB 经 S1-U 到 SGW，再经 S5/S8 到 PGW，最后经 SGi 到互联网。每条隧道有 TEID，因此 S1-U 抓包会看到 GTP 封装。MME 通过 S6a Diameter 向 HSS 获取密钥和资料，PCRF 设定策略和承载 QoS。漫游时 PGW 可能仍在归属网络，数据先绕回本国，因此漫游可能更慢。
