OSPF 与 IS-IS：单个网络内部的地图

每台路由器都掌握所属网络的完整地图，并计算最短路径。

在单个运营商内部，路由器运行 OSPF 或 IS-IS 等链路状态协议，使每台都拥有相同的路由器与链路地图，每条链路带有代价。

通信如何进行

路由器 A路由器 B

  1. 路由器A到路由器B： Hello：我是 A，属于区域 0

  2. 路由器B到路由器A： Hello：我看到你了

  3. 路由器A到路由器B： 这是我的完整链路状态数据库

  4. 路由器 B 给每个人： 我到 C 的链路刚断了（新 LSA）

  5. 每个路由器→自身：再次运行最短路径，更新路由

出问题时

两台路由器的定时器、区域或 MTU 不一致时，无法成为邻居，地图会缺一部分。链路反复上下线，会让全网不断重新计算，造成路由震荡。

更深入

每台路由器泛洪通告自身链路状态，OSPF 使用 LSA，IS-IS 使用 LSP，再用 Dijkstra 算法在完整地图上计算最短路径。光纤中断时，两端通告变化，所有路由器重新计算。调优良好的网络可在一秒内完成，快速重路由备用路径通常更早就绪。BGP 决定出口，OSPF 或 IS-IS 找到通往出口的路。大型运营商常偏好 IS-IS，因为它直接运行于链路层，不依赖 IP，也适应大型单区域。OSPF 则围绕骨干区域 0 划分多个区域。
