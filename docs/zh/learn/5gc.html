5G 核心网：AMF、SMF、UPF 等功能

相互通过 HTTP API 调用的小型独立功能。

AMF 处理注册和移动性，SMF 建立数据会话，UPF 转发数据包，AUSF 与 UDM 验证身份，NRF 提供功能发现目录。

通信如何进行

gNodeBAMF

  1. gNodeB 到 AMF： 注册请求（N2）

  2. AMF → AUSF：验证该订户 (N12)

  3. AMF → SMF：创建 PDU 会话 (N11)

  4. SMF→UPF：设置转发规则(N4)

  5. UPF → 互联网：你的数据包 (N6)

出问题时

AMF 故障会影响注册，SMF 或 UPF 故障则可能已注册却无法上网。切换保留注册却丢失会话时，就会出现“满格无网络”，直到手机重新建立会话。

更深入

5G 核心网采用服务化架构，各功能提供 HTTP/2 API。AMF 与 SMF 通过 N11 通信，N12 连接 AUSF，N8、N10 连接 UDM。gNodeB 经 N2 使用 NGAP 承载 NAS 与 AMF 通信，经 N3 GTP-U 向 UPF 发数据；UPF 经 N6 到互联网或企业网络。SMF 经 N4 PFCP 配置 UPF。功能以软件形式多副本部署在云中，某个故障时由其他副本接管。故障切换测试关心的是数据多久恢复。PCF 管理策略，网络切片让同一核心网承载规则不同的虚拟网络。
