BGP：互联网各网络如何协商路径

成千上万个网络，相互告知自己能到达哪里。

互联网由约 80,000 个网络组成，它们称为自治系统，各有 AS 号。BGP 让它们相互通告：“这些地址可通过我到达。”

通信如何进行

你的运营商转接网络

  1. 你的公交网络运营商： UPDATE：198.51.100.0/24 可经 AS64500 到达

  2. 交通网络 → 世界：更新 - 198.51.100.0/24 通过 AS64510 AS64500

  3. 内容网络 → 中转网络：198.51.100.7 的流量

  4. 传输网络到你的运营商： 按照学到的路径转发

出问题时

错误通告，包括路由泄漏或劫持，可能几分钟内就让大量互联网流量走错路。同一运营商用户访问某网站都慢时，常与对等互联选择有关，而非你的线路。

更深入

各运营商在边界路由器上运行 BGP。路由携带经过的 AS 号路径，通常优先选较短的 AS 路径，但业务策略可改变选择，例如优先便宜的邻居或付费客户。运营商内部用 iBGP 传播这些路由，常借助路由反射器。互联网交换点 IXP 的对等互联让两个网络免费直连；转接服务则是付费通过更大的网络访问其他网络。因此两个距离相近的网站可能速度不同，路径选择也受商业决策影响。AdeeboMeter 的“谁在传输我的流量（BGP）”可显示数据包跨越的网络。
