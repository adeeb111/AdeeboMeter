在线足球直播：邻居为什么先欢呼

直播需要分段、缓存和缓冲，通常落后球场 20 到 60 秒。

比赛画面依次经过摄像机、编码器、分段封装器、CDN 和播放器缓冲。每步都增加几秒，传统 HLS 通常比广播落后 20-45 s。

通信如何进行

球场摄像机编码器

  1. 体育场摄像机到编码器： 实时画面

  2. 编码器→打包器：2 块中的视频

  3. 打包器 → CDN：块 4512

  4. 你的应用 → CDN：请提供最新的块

  5. CDN → 你的应用程序：块 4512 - 它在踢球后播放大约 30 s

出问题时

为降低延迟而缩小缓冲，会提高卡顿风险。手机进球通知比视频更快，是因为通知不用等待视频缓冲。

更深入

低延迟 HLS 和 DASH 将片段拆成更小部分，一生成就传输，可降到 3-8 秒。但缓冲更小，Wi-Fi 稍有波动就更容易卡住。大赛时数百万人同时请求相同片段，是 CDN 最繁忙的时刻。运营商会预置容量，部分在内部使用多播辅助分发。卫星和 IPTV 多播通常比网络应用更接近实时。大赛之夜卡顿常是共享链路拥堵，而非你的线路。
