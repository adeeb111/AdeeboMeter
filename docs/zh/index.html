诚实的限度

没有管理员权限或云服务时，Windows 不允许我们做什么。

AS 编号/BGP 数据

需要互联网服务——只能通过选择加入、定时在线查找。否则，路由器名称就能说明问题。

TCP / UDP 路由跟踪

需要原始套接字（管理员）- 跟踪使用 ICMP。

每个连接的 RTT

需要管理员打开 - 每个应用程序的流量来自实时捕获。

DNS 缓存

某些 Windows 版本上仅限管理员 - 然后名称来自实时捕获。

速度测试

仅针对你运行的服务器（iperf3、bufferbloat、TWAMP-light）——AdeeboMeter 从不监听。

在隧道内或你的 ISP 内

只能推测，没见过。

DSCP 标记

Windows 通常会清除程序请求的标记，除非 QoS 策略允许——只有捕获才能证明这一点。

具有不同缩放比例的屏幕

在 100% 和 200% 屏幕之间移动：Windows 缩放窗口，稍微柔和。
