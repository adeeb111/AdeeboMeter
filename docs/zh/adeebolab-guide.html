AdeeboMeter

模拟网络故障，看看数据包停在哪里。

先在图中模拟故障，再排查真实连接。AdeeboLab 模拟数据包的传输过程，不测量实际网络。

  • 在浏览器中使用
  • 无需安装
  • 阅读约 2 分钟

用两分钟做个实验

  1. 打开 AdeeboLab，选择 Gamer 示例。图中的运营商设备仅作示意，并非探测到的实际硬件。
  2. 选择 Break it，再选择 Wrong gateway。保持起始设备和目标不变。
  3. 按 Play 开始。使用 Step 或 Step back，按自己的节奏查看每一步说明。
  4. 接着尝试 DNS times out，比较域名查询失败与数据包无法离开电脑的区别。

模拟器目前的标签和说明为英文。

打开网络模拟器

实验说明了什么

  • 数据包无法离开电脑在此模拟中，先检查本地路径和网关设置。
  • 域名查询没有响应即使连接的其他部分正常，DNS 也可能出错。
  • 实际连接很慢请进行实际测量。模拟故障不能诊断您的电脑、Wi-Fi 或运营商。
AdeeboLab 会测试我的实际连接吗？

不会。AdeeboLab 只在图中模拟数据包，不发送真实网络流量。请使用 AdeeboMeter 测量 Windows 电脑的实际连接。

需要安装 AdeeboLab 吗？
