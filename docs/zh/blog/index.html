为什么慢？

变慢通常始于五处之一：电脑、Wi-Fi、路由器、运营商或远端。每篇指南用几分钟的测试检查其中一处。

  1. 是 Wi-Fi 还是运营商的问题？

    用网线重复相同操作。有线流畅则说明问题在无线链路，而不是套餐。

    • 测试：Wi-Fi 与网线对比
    • 阅读约 4 min
    1. 电脑
    2. Wi-Fi
    3. 路由器
    4. 运营商
    5. 远端

  2. 有人上传时，网络为什么会变慢？

    同时观察速度和延迟。上传一开始延迟就升高，说明线路满载，而非损坏。

    • 测试：上传时的延迟
    • 阅读约 4 min
    1. 电脑
    2. Wi-Fi
    3. 路由器
    4. 运营商
    5. 远端

  3. 为什么我的电脑速度很慢？

    找出整体卡住时仍持续繁忙的应用，并判断瓶颈在处理器、内存还是磁盘。

    • 测试：实时查看最繁忙应用
    • 阅读约 3 min
    1. 电脑
    2. Wi-Fi
    3. 路由器
    4. 运营商
    5. 远端

  4. 如何向运营商说明丢包从哪里开始？

    生成两分钟报告，标出首个丢包位置，附到工单中。

    • 测试：给运营商的报告
    • 阅读约 4 min
    1. 电脑
    2. Wi-Fi
    3. 路由器
    4. 运营商
    5. 远端

  5. 如何用键盘检查网络？

    先在 AdeeboShell 中运行 status，再探索内置工具，无需离开应用。

    • 试一试：三条内置命令
    • 阅读约 3 min
    statusls /toolshelp ping

  6. 数据包为什么会卡住？

    在 AdeeboLab 中更改一项模拟故障，逐步跟踪数据包。

    • 试一试：浏览器网络模拟
    • 阅读约 2 分钟
    1. 电脑
    2. Wi-Fi
    3. 路由器
    4. 运营商
    5. 远端
