生成报告

  1. 在 Windows 版 AdeeboMeter 中打开 工具箱 并搜索 给网络运营商的报告.
  2. 输入故障服务的地址，或选择已添加的游戏。问题发生时运行 1、2 或 5 分钟。
  3. 条件允许时，改用网线再测，并在恢复正常后再测一次。提交工单前先阅读报告。

如何理解结果

  • 某一跳漏应答，后续却正常该路由器只是没有优先响应 ping，并非丢弃转发流量。应查看目的地行。
  • 丢包从路由器或之前开始问题在家中网络，先比较 Wi-Fi 与网线。
  • 路由器正常，目的地丢包再运行两次，将两份报告发送给运营商。
  • 只有一个服务异常测试无关的目的地。其他目标正常，则问题在该服务一侧。

上方示例

电脑使用网线，路由器正常。丢包在更远处开始，并持续到目的地。发送这种模式，注明测试时间与受影响服务；第二次测试可说明是否重复出现。

为什么单个跳点可能看起来更糟

报告反映某台电脑在某时刻访问一个目的地的观察。路由器可能故意慢答或忽略探测，返程也可能走不同道路。因此跳点编号是排查线索，而非最终定论。

有用的工单应包含什么

时间和时区、网线或 Wi-Fi、受影响服务、发生频率，以及异常和正常时各一份报告。
