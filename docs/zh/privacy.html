AdeeboMeter

隐私政策

AdeeboMeter 应用与网站 · 更新于 2026 年 11 月 24 日

Windows 应用 不收集个人信息，无账号、遥测或使用分析。所有观察结果留在本机，不接受任何入站连接。仅有三个小型 Cloudflare Workers 中继，转发你主动发送的报告、手机连接或手机应用实时信息服务内容，均不保留数据。

AdeeboMeter收集什么

不收集任何内容。开发者不会收到关于你、电脑、网络或使用方式的信息。下述中继仅转发你主动发送的内容，不保存。

哪些内容会保留在你的电脑上

  • 设置 (AdeeboMeter.settings）和一个小 日志 用于对应用程序本身进行故障排除。
  • 历史记录 过去几天的网络速度和健康状况，以便你可以重播出现问题的一分钟。它保存在你的 AppData 文件夹中（标记为便携式的副本将其保存在程序旁边的数据文件夹中），旧的日子会自动删除。
  • 邻居信道大战 （仅当历史记录打开时）：每小时一次，Wi-Fi 网络 Windows 已列出 - 它们的名称、地址 (BSSID)、通道和​​信号 - 保留 7 天 air.txt。关闭历史记录会在一小时内将其删除。这些是每个 Wi-Fi 网络向附近的任何人广播的名称和地址；他们身上的设备什么也看不到。
  • 积分 (points.txt)：你尝试过哪些功能以及何时尝试过。没有别的了。
  • 网络设置快照 (netsnap.txt，仅当你按“保存”时）：适配器的地址、路由器和 DNS 服务器、代理以及主机文件的指纹 - 以显示稍后更改的内容。
  • 评论 （这 reports 文件夹）：你保存的六个月评论 - 并且，当历史记录保存 6 个月时，AdeeboMeter 在最旧的日期滚动之前写入的评论。姓名、Wi-Fi 姓名和地址均被省略。它们会一直保留到你将其删除为止。
  • 流和代理记录 （在历史记录中，保留 90 天）：对于每个流 - 服务的名称（来自其服务器的名称，而不是你的标签或标题）、播放时间和下降时间；经纪商观察 - 每个交易日的缓慢时刻。你的账号和你在服务中观看的内容永远不会被看到。
  • 天气 (weather.txt，仅当你打开天气）：你选择的地点的每小时天气预报 - 最后一天和未来一天，大约 2 KB。没有历史。删除（或关闭天气）会将其删除。
  • 当天的数字 (fx.txt, bcpi.txt)：来自加拿大央行的最新汇率和商品指数，因此交易页面将打开，无需再次询问。
  • 断网日志 （属于历史记录）：记录断网和恢复时间，供断网列表和运营商报告使用。只记时间，不记你在做什么。关闭历史也会停止此记录，旧数据随历史一起清理。
  • 唤醒 （历史记录）：唤醒路由器并DNS应答后多少秒。
  • 各网络中的设备 (devices.txt, device-nets.txt，仅历史开启时保存）：保存各网络已见的硬件地址及首次发现网络的时间，用于识别新设备。最多 40 个网络，关闭历史会同时删除。
  • 走动测试 (walk.txt）：你输入的房间名及各位置测量结果。在页面移除房间即可删除。
  • 已见程序 (seen-apps.txt）：联网程序的名称及首次发现时间，用于指出新程序。
  • 已记住的手机 (phones.txt，仅在你同意“记住此手机”后）：各手机的名称与专属密钥，绑定你的 Windows 账户。“忘记我的手机”可清空。
  • 你的游戏 (games.txt, valve-servers.txt）：玩家专区中添加的游戏与服务器，以及刷新时获得的 Valve 公共服务器列表。开启历史时，还会每分钟记录所监测服务器。
  • 体育 (sportkeys.dat, sporthits.txt）：你添加的 football-data.org 或 CricketData 密钥，绑定 Windows 账户，以及当天 CricketData 请求次数。
  • 市场 (mk-calls.txt，加拿大银行历史文件）：当天使用自有密钥的行情请求次数，以及绘图所需的汇率历史。
  • 播放流检查 (streamlinks.bin, streamchecks.txt）：你保存的播放链接，绑定 Windows 账户，以及检查结果。
  • 服务看板 (board-watch.txt, board-log.txt）：你要求监测的主机，以及各次检查结果。
  • 证书 (cert-compare, cert-dates.txt）：你要求比较或关注的证书链和到期日期。
  • 设备列表 (inventory.txt，仅历史开启时保存）：各网络中你命名或监测的设备。旧条目随历史清理，关闭历史会删除。
  • 精彩时刻与固定时间点 (moments.txt, time-pins.txt）：小助手已展示的小事件，以及你在时光机固定的分钟。
  • 等待发送的报告 （这 outbox 文件夹）：离线时点击发送、且已去除隐私的报告，最多 3 份。下次 AdeeboMeter 联网启动时发送，7 天后仍未发送则删除。
  • 网络实验室 (lab.html, edge-profile）：你打开的实验页面，包含网络设备列表和本机名称，以及所用的私有 Edge 配置，均保留在本机。
  • 捕获 和 保存的结果，但仅限你选择制作或保存的内容。

你在工具中输入的密码和机密（例如 SNMP 社区、RADIUS 机密或证书密码）将用于该一项操作，并且永远不会保存、记录或复制。

当捕获停止、下次开始以及你退出 Windows 时，实时捕获都会被删除。

卸载 AdeeboMeter 会将其删除，但你的加密密钥列表和密钥备份除外（因此发送给你的文件在重新安装后仍然打开；删除 %LOCALAPPDATA%\AdeeboMeter 和 Documents\AdeeboMeter 也将它们删除）。你自己保存的文件保留在你放置的位置。

发送内容以及发送时间

这些都不包含有关你的信息。每个项目都在应用程序中的“关于”>“什么离开你的电脑”下实时列出，每个后台项目都可以在“设置”中关闭。

在后台（应用程序运行时）：

  • 路由器ping： 每隔几秒就会对你自己的路由器进行一次微小的 ping 操作。它保留在你的本地网络上。
  • 上网和DNS检查： 一次 ping 到 1.1.1.1 （或者 8.8.8.8）在 Balanced 上每 15 秒（在 Penny 上每 5 分钟），并且每分钟最多查找一次名称。在阻止 ping 的网络上，与同一地址的端口 443 的定时连接会立即关闭。将其设置为“关闭”，则后台不会有任何内容访问互联网。
  • 运营商名称： 每个网络一次，一条短踪迹（6 跳） 1.1.1.1 以及反向名称查找，以命名你的运营商。
  • 登录页面检查： 仅在你发起的“哪里不对劲？”或全面检查中，向 Windows 同款测试页面发一次请求（msftconnecttest.com).
  • 固定目的地手表： 每 30 秒 ping 一次到你固定的目的地，前提是你将其打开。
  • 玩家专区： 在你单击游戏之前什么都没有。然后 ping（或定时连接）到该游戏的区域； Valve 服务器列表来自 api.steampowered.com 仅当你添加 Valve 游戏或按“刷新”时。
  • 流媒体： 仅当某些内容流时，每 10 秒（Penny 上的 30）与流自己的服务器进行定时连接（无数据），以区分其速度减慢与你的速度 - 如果它从未应答，则最多尝试六次。在“设置”中关闭 ›“你进行直播还是交易？”。
  • 券商观察： 在你选择券商之前什么都没有。然后，仅在市场开放时（或全天候，如果你选择加密货币）按照你预设的速度定时连接（无数据，无需登录）到其公共地址。
  • 天气 （关闭直到你将其打开）：你键入一个地点；它的名字曾经出现过一次 geocoding-api.open-meteo.com 找到它。然后只有它的坐标去 api.open-meteo.com - Better 上大约每 2 天或每 6 小时。你的电脑的位置永远不会被使用。 Open-Meteo是免费的，无需账号；数据抄送 4.0。
  • 加拿大银行号码： 仅市场页面打开或晚间总结开启，且应有较新数据时：列表中每种货币请求一次，首次获取自 2017 起的历史；约每周获取商品指数、政策利率和通胀，来源为 bankofcanada.ca。没有发送任何有关你的信息。
  • 市场行情 （需你自己的密钥）：指数、公司和期货价格来自 financialmodelingprep.com, finnhub.io 或 twelvedata.com ，仅使用你添加了密钥的服务。Finnhub 和 Twelve Data 提供公司价格，不提供指数或期货。市场页面打开时按设定间隔 1-60 分钟获取，公司选择器也查询同一服务。
  • 体育比分 （默认关闭）：体育页面打开时约每 5 分钟，或关注球队比赛且正在播放时，获取当天赛程与比分，来源为 api-web.nhle.com, site.api.espn.com 和 feeds.bbci.co.uk，以及 api.football-data.org 或 api.cricapi.com ，使用你自己的密钥。开启开赛提醒后，仅在所关注比赛临近时，电脑开机期间约每 30 分钟获取赛程。
  • 手机等待室 （仅记住手机后）：在 AdeeboMeter 手机中继建立等待室（adeebometer-remote.orkoadeeb.workers.dev），供手机找到本机。内容已加密，中继无法读取。每小时还会请求一次 adeebometer-live.orkoadeeb.workers.dev 以校准时间。可用手机页面开关关闭，或在 IT 策略中设置 phone_remote = off 。
  • 服务看板监测 （仅设置分钟间隔后）：应用运行时，每隔几分钟与看板各主机建立一次不发送数据的连接。
  • 监测的设备 （仅你选择监测的设备）：在本地网络中每分钟向各设备发送一次 ping。

仅当你启动它们时：

  • 工具： 测试仅联系你键入或选择的目标（或其在屏幕上命名的目标，例如 msftconnecttest.com 用于时钟检查）。
  • 测速： 大约 8 秒下载并上传到你选择的服务器（Cloudflare 最近的服务器） speed.cloudflare.com 默认情况下，或城市中的 Vultr 或 OVHcloud 测试文件），上限为 MB。
  • 我的 ISP 的报告： 向你选择的目标发出 ping 和路由追踪，并向 1.1.1.1 进行并排测试，供手动输入的主机比较；查询公网 IP 时请求一次 www.cloudflare.com/cdn-cgi/trace) 仅当你键入 yes 时。
  • 手机连接： 点击“显示二维码”时，通过 AdeeboMeter 手机中继建立加密连接（adeebometer-remote.orkoadeeb.workers.dev）。手机与电脑之间全程端到端加密，中继只转发，无法读取。
  • 播放流检查： 点击“测试播放流”时，向所提供链接的服务器获取播放列表和最多 30 秒视频。
  • 证书撤销状态 （设置中默认关闭）：运行证书链或 HTTPS 检查时，向签发机构的 CRL 或 OCSP 地址查询一次。
  • 在线查询 （默认情况下关闭，它们会在你选择的时间后自行关闭）：路径的公共 IP 地址转到 RIPEstat（stat.ripe.net) 和 HTTPS 上的 PeeringDB；然后安全检查还会询问 Cloudflare 的加密 DNS (cloudflare-dns.com) 提出一个问题并打开一次 TLS 握手 www.microsoft.com。 VPN 泄漏测试（工具箱，当你按下它时）询问 Cloudflare 的 STUN 服务器（stun.cloudflare.com，UDP 3478），一次通过正常路线，一次通过你的 Wi-Fi 或直接电缆，它会看到哪个地址。加密的 DNS (DoH / DoT) 工具会在运行时询问你选择的服务器。
  • 你点击的链接 （GitHub，捐赠）在浏览器中打开；应用程序本身不发送任何内容。
  • 报告错误、发送反馈、发送你的名人堂卡： 仅当你按下时 发送 在看到盒子里到底装了什么之后。它发送到 AdeeboMeter 的中继（一个小型​​ Cloudflare Worker），该中继将其归档给 Adeeb - 无需账号。错误报告可以添加应用程序的版本、Windows版本、你所在的页面及其日志的最后几行，并删除名称、PC的名称、路径和地址；中继再次剥离电子邮件和 IP 地址。你的互联网地址仅用于计算发送次数（每小时五次），并且仅作为单向哈希保留一天。如果没有互联网，报告会在你的 PC 上等待，并在 AdeeboMeter 下次在线启动时发送。当你的 IT 团队关闭在线查找时关闭。
  • 崩溃报告： 如果应用程序崩溃，下次启动时会在浏览器中打开一个 GitHub 问题页面，并填写详细信息。除非你选择提交，否则不会发送任何内容，你可以先阅读和编辑它。

AdeeboMeter 不监听入站：不开放端口，不在电脑上运行服务器，只接收自己发起请求的应答。

Microsoft Store

如果 Microsoft Store 中提供了 AdeeboMeter，并且你从 Microsoft Store 安装了 AdeeboMeter，则 Microsoft 将根据以下条件处理下载、更新和任何购买数据： 微软的隐私声明。开发人员只能看到 Microsoft 向每个发行商提供的匿名总数，例如安装数量。

这个网站

公开网站使用 Cloudflare Web Analytics 测量浏览量、访问量、来源网站和页面性能，帮助了解哪些指南有用并改进网站。不使用分析 Cookie 或浏览器指纹，访问数是根据页面请求和来源估算的。

分析脚本加载自 static.cloudflareinsights.com ，并向 Cloudflare 发送测量数据。Cloudflare 作为服务提供商接收网络请求。详情请阅读 Cloudflare 数据收集文档。网站尊重 Do Not Track 和 Global Privacy Control，任一信号开启时都会跳过分析。

网站还使用以下外部服务：主页请求 api.github.com 获取最新版本号，并从以下来源显示 Microsoft Store 徽章： get.microsoft.com；反馈和名人堂表单加载 Cloudflare Turnstile（challenges.cloudflare.com），免费验证发送者是真人而非机器人，无需解谜，也不用追踪 Cookie。实时信息页面和手机应用查询 AdeeboMeter 的实时服务（adeebometer-live.orkoadeeb.workers.dev），获取天气、比分和网站检查；主动运行手机检查时，会联系所测试的目标，例如 Google、Cloudflare、Microsoft 和 Apple 的测试页面、你选择的流媒体与通话服务、公共 DNS 解析器、 rdap.org 以查询地址所有者，以及 Cloudflare 测速服务。与访问普通网站一样，这些服务能看到你的 IP。你发送的消息通过上文所述的 AdeeboMeter 中继转发。

孩子们

AdeeboMeter 不会收集任何人的个人信息，包括儿童。

变更及联系方式

如果此政策发生更改，新版本将在此页面上发布并注明新日期。源代码公开于 GitHub，任何人都可检查应用的行为。若有问题，可通过主页的 表单联系 Adeeb ，无需账号。
