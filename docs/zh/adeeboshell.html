AdeeboMeter

一条命令，完成一项网络检查。

在 AdeeboMeter 中打开 终端，查看当前状态、查找工具，再运行所需的检查。

  • Windows 10 和 11
  • AdeeboMeter 1.1.6
  • 阅读约 3 min

开始第一次检查

  1. 打开 AdeeboMeter 完整窗口，选择 终端。在应用的其他页面中，可按 Ctrl + ` 打开。
  2. 输入 status 并按 Enter，查看已有的测量结果；没有测量结果并不代表检查通过。
  3. 输入 ls /tools 浏览工具分组。尝试不熟悉的命令前，请先使用 help。

Tab 可补全命令，Ctrl+C 可停止当前命令。

查看结果

  • 响应慢或没有响应换一个目标，并在连接正常时再次比较。单次检查失败不能独立确定原因。
  • 不熟悉的命令先阅读帮助。命令可能会发送网络流量或处理文件。
终端 能修改我的 Windows 文件吗？

不能。终端 中的 Windows 文件夹和磁盘为只读，文件修改仅限 AdeeboMeter 的 /data 文件夹。

如何停止 终端 命令？

按 Ctrl+C 停止当前命令。

保留一组有用的对比

先运行 status。出现问题时重复相同检查，并记录时间、目标和结果。
