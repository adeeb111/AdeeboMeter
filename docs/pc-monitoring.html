When everything stalls at once, something on the PC is usually busy. Find the app, and whether it's the processor, the memory or the disk, while it's happening.

  • You need: nothing else
  • About 5 minutes
  • 3 min read

Run the checks

  1. Decide whether the whole PC feels slow or only online things do.
  2. While it's happening, open AdeeboMeter or the Windows Task Manager and look at the processor, memory, disk and network.
  3. Note the app that was busy, and compare with the same PC when it's quick.

Reading it

  • The processor stays highFind the busiest app and close or pause it.
  • Memory is low and the disk is busySave your work, close one big app and try again.
  • The disk stays busyLook for a backup, an update or a virus scan.
  • Only online things stallIt's not the PC. Check the delay to your router and the internet.

An example

The browser and File Explorer both hang during a big backup. The disk stays busy through every stall and settles when the backup ends. Try the same things afterwards: if they're quick, you've found the cause and a test you can repeat.

Why high memory isn't always a problem

Windows fills spare memory with cache, so a high number alone means little. Low available memory, stalls and a busy disk together point to memory pressure. A disk can also be busy without moving much data, when lots of small requests keep it working. More in the memory pressure lesson.

What to keep

What you were doing, the time, what stayed busy, and what changed when it eased.

With history on, AdeeboMeter's Time machine shows the PC and the network from the same minute. If only online things are slow, check the connection path.

The busiest app, named on your desktop

The speed + apps widget lists the apps working hardest right now, beside your speed and the five stops - so a stall has a name the moment it happens.
