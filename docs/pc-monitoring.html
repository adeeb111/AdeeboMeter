Run the checks

  1. Decide whether the whole PC feels slow or only an online task is affected.
  2. While it happens, open AdeeboMeter or Windows Task Manager and inspect CPU, memory, disk, and network.
  3. Identify the process or task that was active. Compare against the same PC when it is responsive.

What to check next

  • CPU stays highFind the busiest process.
  • Memory is low and disk is busySave your work, close one large app, and retry.
  • Disk stays busyCheck for a backup or update.
  • Only online tasks stallCheck router and internet latency.

Worked example

Your browser and file manager both hesitate during a large backup. Disk activity stays high during the stalls and settles when the backup ends. Try the same actions afterward. If the problem disappears, you have a workload to investigate and a repeatable comparison.

Why it works

High memory usage alone can reflect caching. Low available memory, stalls, and changes in disk activity together make memory pressure more worth investigating. Disk active time and transfer rate measure different things. Small requests can keep a disk busy without moving much data.

For a deeper look, use the memory pressure lesson and compare resource behavior over the same interval.

Use AdeeboMeter on Windows

Keep the desktop widget visible while you work, then open the full view to inspect the busiest processes. With history enabled, use Time Machine to review the PC and network readings from the same minute. If only online tasks are affected, check the connection path.
