আপনার পিসিDNS

  1. আপনার পিসি থেকে DNS: github.com-এর ঠিকানা কী?

  2. DNS থেকে আপনার পিসি: 140.82.112.3

  3. আপনার পিসি → সার্ভার: SYN

  4. সার্ভার → আপনার পিসি: SYN-ACK

  5. আপনার পিসি → সার্ভার: ACK + TLS hello

  6. সার্ভার → আপনার পিসি: সার্টিফিকেট + কী

  7. আপনার পিসি → সার্ভার: GET /

  8. সার্ভার → আপনার পিসি: 200 OK + পেজ
