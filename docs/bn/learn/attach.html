মোবাইল, LTE ও 5G

ফোন যেভাবে যুক্ত হয়: LTE attach ও 5G নিবন্ধন

প্রথমে পরিচয় দিন, তারপর তা যাচাই করুন। শেষে পাবেন আপনার ঠিকানা।

নেটওয়ার্কে যোগ দেওয়ার দুটি অংশ আছে। নিবন্ধনে SIM-এর কী দিয়ে পরিচয় যাচাই হয়। ডেটা সেশনে IP ঠিকানা আর ডেটা চলার পথ তৈরি হয়। 4G-তে attach-এর সঙ্গে ডিফল্ট বেয়ারার তৈরি হয়। 5G-তে PDU সেশন আলাদা ধাপ।

কীভাবে বার্তা আদান-প্রদান হয়

ফোনAMF

  1. ফোন থেকে AMF-এ: Registration Request: নিবন্ধনের অনুরোধ

  2. AMF থেকে ফোনে: Authentication Request: পরিচয় যাচাইয়ের চ্যালেঞ্জ

  3. ফোন থেকে AMF-এ: Authentication Response: পরিচয় যাচাইয়ের উত্তর

  4. AMF থেকে ফোনে: Registration Accept: নিবন্ধন গৃহীত

  5. ফোন থেকে AMF-এ: PDU Session Establishment Request: DNN internet-এর জন্য অনুরোধ (SMF-এ পাঠানো হয়)

  6. AMF থেকে ফোনে: SMF থেকে PDU Session Establishment Accept: IP 100.70.3.9

সমস্যা হলে কী হয়

রাউটারের স্ক্রিনে “Registered” দেখালে বোঝা যায় প্রথম ধাপ হয়েছে। অন্য কারণ ধরার আগে সেশন গৃহীত হয়েছে কি না আর একটি IP ঠিকানা এসেছে কি না দেখুন।

আরও বিস্তারিত

4G-তে ধাপগুলো হলো attach request → পরিচয় যাচাই (নেটওয়ার্ক এমন চ্যালেঞ্জ পাঠায় যার উত্তর শুধু আপনার SIM দিতে পারে) → security mode → MME গেটওয়েগুলোর কাছে সেশন চায় → IP-সহ attach accept → ডিফল্ট বেয়ারার চালু। 5G SA-তে registration request → পরিচয় যাচাই → security mode → registration accept। তারপর ফোন একটি DNN-এর জন্য PDU সেশন চায়। DNN হলো APN-এর 5G নাম। SMF একটি UPF ও ঠিকানা বেছে নেয়, তারপর PDU session accept আসে। যেকোনো ধাপ কারণের কোডসহ ফিরিয়ে দেওয়া হতে পারে, যেমন “DNN not supported” বা “insufficient resources”। মডেমের লগে “PDU Session Establishment Request”-এর পরে accept বা reject না থাকলে, সিগন্যালের আগে সেশনের সমস্যা খুঁজুন।
