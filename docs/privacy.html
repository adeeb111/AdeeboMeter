Privacy Policy

AdeeboMeter for Windows · last updated 12 November 2026

In short: AdeeboMeter collects nothing about you. There is no account, no telemetry, no analytics and no server. Everything it learns stays on your PC, and it never accepts a connection from anywhere.

What AdeeboMeter collects

Nothing. The app has no server to send data to, and the developer receives no information about you, your PC, your network or how you use the app.

What stays on your PC

  • Settings (AdeeboMeter.settings) and a small log for troubleshooting the app itself.
  • History of your network's speed and health for the last days, so you can replay a minute that went wrong. It's kept in your AppData folder and old days are removed automatically.
  • Neighbour wars (only while History is on): once an hour, the Wi-Fi networks Windows already lists - their names, addresses (BSSIDs), channels and signal - kept 7 days in air.txt. Turning History off deletes it within the hour. These are names and addresses that every Wi-Fi network broadcasts to anyone nearby; nothing about the devices on them is seen.
  • Adeebo Points (points.txt): which features you've tried and when. Nothing else.
  • Network settings snapshot (netsnap.txt, only when you press Save): your adapters' addresses, routers and DNS servers, the proxy, and a fingerprint of the hosts file - to show what changed later.
  • Reviews (the reports folder): the six-month review you save - and, when History is kept for 6 months, the one AdeeboMeter writes before the oldest days roll off. Names, the Wi-Fi name and addresses are left out. They stay until you delete them.
  • Wake-ups (in History): how many seconds after waking the router and DNS answered.
  • Captures and saved results, but only the ones you choose to make or save.

Passwords and secrets you type into a tool (for example an SNMP community, a RADIUS secret or a certificate password) are used for that one action and are never saved, logged or copied.

Live captures are deleted when a capture stops, at the next start and when you sign out of Windows.

Uninstalling AdeeboMeter removes it, except your encryption key list and key backups (so files sent to you still open after a reinstall; delete %LOCALAPPDATA%\AdeeboMeter and Documents\AdeeboMeter to remove them too). Your own saved files stay where you put them.

What it sends, and when

None of this carries information about you. Each item is listed live in the app under About › "What leaves your PC", and each background item can be switched off in Settings.

In the background (while the app runs):

  • Router ping: a tiny ping to your own router every few seconds. It stays on your local network.
  • Internet and DNS check: one ping to 1.1.1.1 (or 8.8.8.8) and one name lookup about every 30 seconds. On networks that block ping, a timed connection to port 443 of the same address instead, closed at once. Set it to Off and nothing goes to the internet in the background.
  • Provider name: once per network, a short trace (6 hops) toward 1.1.1.1 and a reverse name lookup, to name your provider.
  • Sign-in page check: only when a check fails, one request to the test page Windows itself uses (msftconnecttest.com).
  • Pinned destination watch: one ping every 30 seconds to a destination you pinned, only if you switch it on.
  • Gamer Zone: nothing until you click a game. Then pings (or timed connections) to that game's regions; the Valve server list from api.steampowered.com only when you add a Valve game or press Refresh.

Only when you start them:

  • Tools: a test contacts only the target you typed or picked (or the one it names on screen, such as msftconnecttest.com for the clock check).
  • Speed test: about 8 seconds of download and upload to the server you picked (Cloudflare's nearest speed.cloudflare.com by default, or a Vultr or OVHcloud test file in a city), with a cap in MB.
  • Report for my ISP: pings and traces to the destinations you choose; your public IP (one request to www.cloudflare.com/cdn-cgi/trace) only if you type yes.
  • Online lookups (off by default, and they switch themselves off after the time you choose): public IP addresses of a path go to RIPEstat (stat.ripe.net) and PeeringDB over HTTPS; the Security checkup then also asks Cloudflare's encrypted DNS (cloudflare-dns.com) one question and opens one TLS handshake with www.microsoft.com. The Encrypted DNS (DoH / DoT) tool asks the server you choose when you run it.
  • Links you click (GitHub, Donate) open in your browser; the app itself sends nothing.
  • Crash reports: if the app crashes, the next start offers to open a GitHub issue page in your browser with the details filled in. Nothing is sent unless you choose to submit it, and you can read and edit it first.

AdeeboMeter never listens: it opens no ports and runs no server, and only receives replies to requests it made.

Microsoft Store

If AdeeboMeter is offered in the Microsoft Store and you installed AdeeboMeter from the Microsoft Store, Microsoft handles the download, updates and any purchase data under Microsoft's privacy statement. The developer only sees the anonymous totals Microsoft provides to every publisher, such as the number of installs.

This website

The page loads nothing from other sites, with one exception: it asks GitHub's API (api.github.com) for the latest version number, so GitHub sees your IP address the way any website you visit does.

Children

AdeeboMeter doesn't collect personal information from anyone, including children.

Changes and contact

If this policy changes, the new version will be posted on this page with a new date. The source code is public on GitHub, so anyone can check what the app does. For questions, open an issue at github.com/adeeb111/AdeeboMeter/issues.
