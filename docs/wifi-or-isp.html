Is it your Wi-Fi or your internet provider?

Run the checks

  1. Write down the time and reproduce the issue with the same site, call, or download.
  2. Try the same task on a second device connected to the same Wi-Fi. On a phone, make sure it is using Wi-Fi during the comparison.
  3. Connect the PC directly to your router by Ethernet, turn off Wi-Fi on that PC, then repeat the same task while the slowdown is happening.

What the results suggest

What you seeWhat to check next
Ethernet works, Wi-Fi still strugglesRepeat closer to the router. Improvement points toward signal, interference, or the wireless link.
Only one device strugglesCheck that device for high resource use, a busy transfer, or a VPN. Compare again before changing the router.
Both connections struggle on several devicesTry unrelated services. Check local router response and look for an outage with your provider.
Only one website or game strugglesTry another service on the same connection. The affected service or its network path deserves a closer look.

Worked example

An evening video call freezes upstairs. The same laptop runs the call smoothly on Ethernet, and the call also improves when the laptop moves closer to the router on Wi-Fi. Start with wireless coverage. If the call also freezes on Ethernet and another device, check the router and the wider connection instead.

Why this test works

Run ipconfig and find Default Gateway under the active adapter. Ping that address during a good period and again during a slowdown. Compare with an internet destination that normally answers ping. Repeat the comparison when possible. A router can de-prioritize ping replies, so weigh the replies alongside the Ethernet comparison and what the affected service is doing.

Steady replies from your router with trouble beyond it on multiple devices gives support a more useful starting point. The test can still leave the modem, provider, and farther network path in contention.

Use AdeeboMeter on Windows

Open Investigate → The internet is slow. Check the PC, Wi-Fi, router, DNS, and internet results from the same period. For recurring trouble, monitor internet speed over time and make a report for your provider.

What to keep

Keep one comparison from a good period and one from the slowdown. Record the connection type and affected services so you can repeat the test.
