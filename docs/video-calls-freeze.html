Why do video calls freeze when internet speed looks fine?

Run the checks

  1. Note when the freeze happens and whether the audio cuts out too.
  2. Pause a large upload you control. See if the call clears.
  3. Repeat on Ethernet with Wi-Fi off. Use the same PC and call service.

What to check next

  • Ethernet clears itTry Wi-Fi closer to the router.
  • Pausing an upload helpsCheck whether latency rises during uploads.
  • Only this PC strugglesCheck CPU usage and try with the camera off.
  • Only one call service strugglesCompare another service on the same connection.
Why it works
  • Bandwidth tells you how much data can move.
  • Latency is how long data takes to arrive.
  • Jitter is how much that delay varies.
  • Packet loss is data that never arrives.

A speed test samples one path at one moment. A live call needs packets to arrive steadily throughout the call.

Check it in AdeeboMeter

Open Investigate → Calls freeze or sound robotic while the problem is happening. Note which readings change at the same time as the freeze.
