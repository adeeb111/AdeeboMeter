جهازكDNS

  1. جهاز الكمبيوتر الخاص بك إلى DNS: أين موقع Github.com؟

  2. DNS إلى جهاز الكمبيوتر الخاص بك: 140.82.112.3

  3. جهاز الكمبيوتر الخاص بك → الخادم: SYN

  4. الخادم → جهاز الكمبيوتر الخاص بك: SYN-ACK

  5. جهاز الكمبيوتر الخاص بك → الخادم: ACK + TLS مرحبا

  6. الخادم → جهاز الكمبيوتر الخاص بك: شهادة + مفتاح

  7. جهاز الكمبيوتر → الخادم: GET /

  8. الخادم → جهاز الكمبيوتر الخاص بك: 200 OK + الصفحة
