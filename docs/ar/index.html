هذا الكمبيوتر (27)

مكافحة الفيروسات، والجدار الناري، وBitLocker وSecure Boot وUAC، والتحديثات ودعم إصدار Windows، وSMBv1 وRDP وNLA، والمنافذ المفتوحة، والشهادات الجذرية المضافة، وملف hosts والوكيل، وبرامج بدء التشغيل غير الموقّعة، والمهام المجدولة الخطرة، وCredential Guard وسلامة الذاكرة وقفل الشاشة وشبكات Wi-Fi المفتوحة.

شبكتك (11)

أمان Wi-Fi، وخوادم DNS التي تغيّر الإجابات، وفك تشفير https أثناء مروره، وعلامات انتحال ARP، ووجود خادم DHCP إضافي، وUPnP في الراوتر، وصفحة الإدارة عبر http، وTelnet / FTP، وتسرّب DNS عند استخدام VPN، والأجهزة الجديدة.

مواقعك (4)

انتهاء صلاحية الشهادة، TLS القديم لا يزال مقبول، رؤوس الأمن، SPF / DKIM / DMARC.

بطاقة النتيجة، المشاكل أولاً

المعلومات المخاطر التي تستحق النظر فيها انقر على الشيك لتشغيله مرة أخرى، نسخ البطاقة بأكملها من أجل تذكرة.

مدخلات معتمدة

المواقع تتحقق من قبل أي شيء مسارات التقاط المقصورة داخل مجلد AdeeboMeter الخاص.

TLS فعل بشكل صحيح

فقط TLS 1.2 / 1.3؛ Windows يؤكد الشهادات؛ لا يتم إرسال أي شيء عبر اتصال غير موثوق به.

DLL فقط من System32

في كل العملية — لا يتم تحميل DLL المزروع بجوار exe في Downloads.

لا شيء ليتم اختطافه

لا تحديثات، لا سلسلة ثنائية، لا XML محلل، لا أسرار في الشفرة. يتم إخفاء أسرار RADIUS وكلمات المرور في مجتمعات SNMP / v3 ولا يتم حفظها أبداً.

بناء يمكن إثباته
