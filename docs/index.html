AdeeboMeter · Theory of Everything05
The heart · Monitor

Two threads do all the watching.

Sampler — every second

  • CPU, memory, disk and network bytes
  • TCP/IP health: retransmits, resets, failed connections, unreachables, UDP drops
  • Every 10 s it judges: OK / Busy / Act, and one sentence
  • Optional: one line to today's 7-day history file

Probe — every 2 to 10 seconds

  • Router ping · internet + DNS check (cache skipped)
  • Adapters, VPN, DNS server, MTU — changes become events
  • Gateway spoof watch: the router's MAC must not change
  • Wi-Fi signal, roams, drops — and Windows' reason for a drop
  • Apps and connections · Teams calls get the fast pace

AdeeboMeter · Theory of Everything11
SNMP

Ask a switch or router - in plain words.

Views that answer questions

Snapshot · interfaces with problems first and what changed since your last run · traffic · CPU · LLDP · sensors · find a MAC · VLANs · PoE · LAG · printer · UPS.

Walk anything

Any OID or MIB name, up to 2,000 values, paced - rebuilt into tables joined by index, the useful columns first.

Your own MIBs

Drop a vendor's .mib files in a folder. A strict reader indexes names, tables and descriptions once; nothing in a MIB is ever run.

Search, then walk

Type temperature, optic or fan - matching objects with their description, one click walks that table.

v2c and v3

No auth, auth (MD5 / SHA-1 / SHA-256) and AES-128 privacy - MD5 and SHA-1 keys checked against RFC 3414's own test vectors, SHA-256 against an independent computation. Masked, kept for the session only.

Read-only, always

GET and GETBULK only. It never sets a value and never listens for traps. A column it couldn't read says n/a - never 0.

The path story

Who carries your traffic — and what's in the way.

NAT

Double NAT and carrier-grade NAT (100.64.x.x) spotted from the hop addresses.

Tunnels

From the packet size: 1492 = PPPoE; smaller = VPN, LTE or satellite.

Firewalls

And more

AdeeboMeter · Theory of Everything19
Security

Hardened by design, proven by checks.

No shell, ever

Windows tools by full System32 path, fixed arguments, a timeout, inside a job object that dies with the app.

Inputs validated

Destinations checked strictly before anything runs. Capture paths fenced inside AdeeboMeter's own folder.

TLS done right

Only TLS 1.2 / 1.3; Windows validates certificates; nothing is sent over an untrusted connection.

DLLs only from System32

For the whole process — a DLL planted next to the exe in Downloads is never loaded.

Nothing to hijack

No updater, no binary serializers, no XML parser, no secrets in the code. RADIUS secrets and SNMP communities / v3 passwords are masked and never kept.

A provable build

Built by GitHub from this source, actions pinned to exact commits. The build can only read; a separate release step signs provenance. SHA-256 on every file, 0 analyzer findings.

AdeeboMeter · Theory of Everything22
Honest limits

What Windows doesn't let us do without admin or the cloud.

AS numbers / BGP data

Need an internet service — only through the opt-in, timed online lookups. Otherwise router names tell the story.

TCP / UDP traceroute

Needs raw sockets (admin) — traces use ICMP.

Per-connection RTT

Needs admin to switch on — per-app traffic comes from live capture instead.

The DNS cache

Admin-only on some Windows builds — then names come from live capture.

Speed tests

Only to a server you run (iperf3, bufferbloat, TWAMP-light) — AdeeboMeter never listens.

Inside a tunnel or your ISP

Can only be inferred, never seen.

DSCP marking

Windows usually clears a marking a program asks for unless a QoS policy allows it — only a capture proves it.

Screens with different scaling

Moving between a 100% and a 200% screen: Windows scales the window, slightly soft.

Policies

Code signing and privacy.

✓

Code signing policy

Releases aren't code-signed yet; we're applying for free open-source signing from SignPath Foundation. Every release file is built by this project's GitHub Actions workflow from the public source — never on a personal PC — with every action pinned to an exact commit, and each release is approved by hand. Team roles (committer, reviewer, approver): adeeb111, with multi-factor authentication.

✓

Privacy policy

AdeeboMeter will not transfer any information to other networked systems unless you ask it to. It never listens, has no telemetry, no account and no updater. Checks and tools contact only what you typed or what they name on screen; About lists every packet your settings send.

✓

Online lookups

Off by default. Switched on for 5 minutes to 3 hours, they send public IP addresses only — never private addresses or names you typed — to RIPEstat and PeeringDB, then turn themselves off. Everything else stays on your PC; uninstalling removes it.
