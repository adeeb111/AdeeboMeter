A lab you can start on your phone

Open AdeeboLab Playground. It runs in the browser with no account. Use Start fresh for a blank canvas, or open an example to skip the drawing.

Try a five-minute experiment

  1. Place a laptop, router and server. Pick a tool, then tap or click the canvas. Select a device to rename it.
  2. Connect the devices. Keep the first diagram small enough to explain in one sentence.
  3. Switch to Break it. Try one supported fault and follow the simulated packet. Restore it before changing something else.
  4. Save the project. A project file keeps an editable copy. A PNG or SVG is a picture of it.

Find the problem on your real connectionMeasurements from the affected device, such as the Windows app.
What this browser lab cannot tell you

AdeeboLab does not discover your home network, run real router firmware or prove that a live connection will behave like the drawing. Its examples simplify networking to make one cause visible. Hardware-specific behavior, real throughput and production configuration need other tests.

Move the diagram from phone to PC

Choose Project → Share by QR code. The other device opens an editable snapshot, not a live collaboration session. Anyone with that link can read its contents. Large projects use the project-file route instead.

Keep the experiment small.

One path. One fault. One explanation. Save your project before clearing browser data; cached diagrams are a convenience, not a backup.

Prefer commands? Try the browser terminal.
