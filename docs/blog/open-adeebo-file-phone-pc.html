Got an encrypted file? Start with how it was locked.

A .adeebo file is an encrypted package. The extension alone does not tell you what unlocks it: some files use a sharing code; others are locked to a recipient’s private key.

  • Phone and PC
  • 3 min read
  • Reviewed 27 November 2026

Open a file that came with a code

  1. Save the encrypted attachment on the device where you want to open it.
  2. Open the Files tool in a compatible HTTPS browser. Use the Open a file section.
  3. Choose the .adeebo file and type the sharing code supplied by the sender.
  4. Open it. If the integrity check passes, the browser downloads the decrypted original. Check your Downloads or Files app.

This can work on the same phone that received the attachment. There is no requirement to install the Windows app for a supported code-protected file.

When you do need the Windows app

What the sender madeWhat opens it
Code-protected .adeeboThe browser Files tool or AdeeboMeter on Windows, plus the code.
P-384 recipient-key .adeeboAdeeboMeter on Windows with the matching private key. A public key alone cannot decrypt it.
Private-key backup .adeeboThe Windows key-restore workflow and its recovery passphrase.
Standard RSA-recipient .p7mA compatible CMS reader with the recipient’s private key, including the Windows app.

A different Windows PC needs the matching private key restored through the supported backup workflow. Installing AdeeboMeter alone does not recreate a key from the original PC.

If it will not open

  • “Wrong code, or the file was changed”Ask the sender to confirm the full code and resend the original encrypted file. That message does not distinguish a typo from damaged or modified data.
  • “This kind opens on a PC only”The file is not the browser’s supported code mode. Ask whether it was made for a private key or is a key backup.
  • File too large or browser runs out of memoryTry the Windows app or ask for a smaller file. Browser limits are 100 MiB on detected mobile/low-memory devices and 300 MiB otherwise.
  • No code or private keyAsk the sender. Renaming the extension or installing another copy of the app does not supply the missing secret.

After opening, the copy is ordinary again

The downloaded original is no longer encrypted by this wrapper. Store it appropriately and remove unwanted copies using your device’s normal file controls. The tool does not securely erase your original or guarantee forensic removal of downloads.

Ask one question first.

“Did you lock this with a code, or for my private key?” That answer determines the reader and credentials you need.
