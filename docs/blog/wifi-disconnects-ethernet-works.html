Wi-Fi disconnects. Ethernet keeps working.

A stable wired comparison points you toward the wireless side: the PC’s adapter, signal, access point or Wi-Fi settings. It does not identify which one failed.

  • Windows 10 and 11
  • 3 min read
  • Reviewed 27 November 2026

Find out what actually disconnects

  1. Watch the Windows connection status. Does Wi-Fi leave the network, or stay connected while internet access disappears? Write down the time and network name.
  2. Compare the same task over Ethernet. Turn Wi-Fi off for the wired test so you know which link is in use. Keep the same PC and service.
  3. Try Wi-Fi near the router, then another device. Keep the Wi-Fi network fixed. Note whether the drop follows one PC, one location or several devices.

Use the narrowest clue

  • One PC drops Wi-FiReview its adapter and the device maker’s driver guidance. Record any exact Windows error before changing settings.
  • Several Wi-Fi devices drop; wired stays stableReview the access point, wireless settings and router logs. This is different from all devices losing internet together.
  • Wi-Fi stays connected but sites failCompare router reachability and more than one destination. “Connected” alone does not show that DNS or the internet path works.

Put a time beside the drop

Watch the router and internet readings in AdeeboMeter and note the incident time. Pair them with Windows connection status; a failed probe by itself does not prove that Wi-Fi disconnected.

Keep one useful comparison

Keep the network name, device, location, time and wired comparison. Use those details when reviewing router or adapter support guidance.
