Lock and open files

.adeebo files, the same as AdeeboMeter on Windows. It all happens on this phone, even offline - nothing is uploaded.

Open a .adeebo file

Someone sent you a file and told you its code another way.

Lock a file

Makes a .adeebo file and a new code. Send the file one way and the code another (say it, or text it) - whoever has both can open it here or on a PC.

The code isn't saved anywhere - write it down or send it before you leave this page.

Up to 300 MB on a phone (the whole file is held in memory while it's locked or opened). Bigger files: use AdeeboMeter on your PC.

AES-256 with a 24-character code (about 119 bits), checked before anything is shown: a wrong code or a changed file opens nothing. Back to the app
